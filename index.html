                    同步設定

                    筆記同待辦會存喺你 GitHub 一個 private repo，每部機（電腦、iPhone）都要入一次。未設定嘅話，就只會存喺呢部機。

                    點樣整 token
                    1. GitHub → 右上角頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
                    2. Repository access 揀 Only select repositories，只揀放筆記嗰個 repo（例如 notes-data）。
                    3. Permissions → Repository permissions → Contents: Read and write，其他唔使郁。
                    4. Expiration 揀長啲（例如 1 年），整好之後複製個 token 貼落上面。
